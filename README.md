# Algorithms & Data Structures

A personal repository where I practice algorithms and data structures, improve my problem-solving skills, and learn how to write efficient code.

The main goal of this repository is not just to implement algorithms, but also to understand how they work, why they work, and how efficient they are.

## 🎯 Goals

- Improve problem-solving and logical thinking.
- Learn and implement fundamental algorithms.
- Understand common data structures.
- Analyze time and space complexity using Big O notation.
- Write clean, readable, and efficient code.
- Document the logic behind every implementation.

## 📖 My Approach

For each algorithm, I aim to include:

1. **Description** – What the algorithm does.
2. **How It Works** – Step-by-step explanation of the logic.
3. **Implementation** – Source code.
4. **Example** – Input and expected output.
5. **Complexity Analysis** – Time and space complexity (Big O).
